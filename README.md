# WebExcel - Product Management System

A web-based product catalog and order management system with Excel import/export functionality.

## Features

- 📦 **Admin**: Import products from Excel files
- 🛍️ **Customers**: Browse products and place orders
- 📊 **Dynamic Columns**: Support for any Excel column structure
- 📁 **Order Management**: Download and delete orders as Excel files
- 🗄️ **PostgreSQL**: Robust database with JSONB support

## Tech Stack

- **Frontend**: HTML, Bootstrap 5
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **File Processing**: exceljs library

## Prerequisites

- Node.js (v14 or higher)
- PostgreSQL (v12 or higher)
- npm or yarn
